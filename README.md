# KFZ Ersatzteile by ZJ – GitHub Pages

## Hochladen vom iPhone
1. Lade `ZJ_Luxus_Website_GitHub.zip` herunter und öffne sie in der Dateien-App, damit iOS sie entpackt.
2. Öffne Safari und gehe zu https://github.com/ZjErsatzteile/ZJ.ErsatzTeile
3. Melde dich an. Falls nötig: in Safari auf `aA` tippen → „Desktop-Website anfordern“.
4. Im Repository `Add file` → `Upload files` wählen.
5. Wähle die entpackte `index.html` aus der Dateien-App.
6. Tippe auf `Commit changes`.
7. Öffne `Settings` → `Pages`; wähle `Deploy from a branch`, Branch `main`, Ordner `/ (root)` und `Save`.

Die Seite ist eine statische HTML-Datei; kein Build-Schritt ist nötig.
