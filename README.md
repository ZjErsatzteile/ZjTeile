# ZJ Ersatzteile – Website

## Veröffentlichung mit GitHub Pages
1. Öffne dein Repository: https://github.com/ZjErsatzteile/ZJ.ErsatzTeile
2. Lade `index.html` aus diesem Paket in das Hauptverzeichnis des Repositorys hoch.
3. Öffne **Settings → Pages**.
4. Wähle unter **Build and deployment** die Bereitstellung über **Deploy from a branch**.
5. Wähle den Branch (z. B. `main`) und den Ordner `/ (root)`, dann **Save**.

Die Seite ist eine statische HTML-Seite und benötigt keinen Build-Schritt.
